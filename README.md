# albers

Research notes on Josef Albers, color interaction, perception, and computational models of color.

## Experiments

- [Single pixel](single-pixel/) — one RGB8 swatch, CIELAB coordinates, local one-code deformations, and an ARMv7/Thumb-2 conversion kernel.
- [Two pixels side by side](two-pixels-side-by-side/) — the ordered two-color boundary before any contextual/perceptual interaction law is assumed.
- [Plate renderer](plate-renderer/) — Haskell reconstruction of sourced Albers plates from physical-coordinate geometry, with PNG/PPM output and scan-measured RGB8 values kept separate from claims about original paper colors.
